# Мастер план небольшой территории

Навык для Codex помогает составить и проверить план улучшений квартала, микрорайона или другой небольшой территории. Он связывает предложения с картой, снимками, рельефом, правилами и повседневными нуждами людей.

Навык помогает:

* найти проблемы и сгруппировать решения по занятиям людей;
* указать место, размер и основание для каждой меры;
* учесть пути, зелень, воду, погоду, уход за местом и местные правила;
* отделить подтверждённые факты от предложений и вопросов, которые требуют проверки;
* подготовить понятную карту и проверить готовый план.

Главные инструкции находятся в [SKILL.md](SKILL.md). Папка [references](references) содержит каталог решений, примеры, правила работы с источниками и способы проверки плана.

Чтобы использовать навык в проекте, скопируйте папку `small-area-masterplan` в `.agents/skills/`. Затем попросите Codex применить его к своей территории и передайте границы участка и доступные данные.
